OAUTH SETUP GUIDE

🔐 OAuth Credentials Required

To enable real Google and GitHub login, you need to create OAuth apps and add your credentials to the .env file. This is a one-time setup.

⚡ Quick Setup: Follow the steps below for your chosen provider. After adding credentials, restart the server with node server.js and OAuth will be fully live.
🇬
Google OAuth 2.0
Google Cloud Console → APIs & Services → Credentials
  1. Go to console.cloud.google.com/apis/credentials
  2. Click Create Credentials → OAuth 2.0 Client ID
  3. Application type: Web application
  4. Add Authorized redirect URI:
    http://127.0.0.1:3000/api/auth/google/callback
  5. Copy your Client ID and Client Secret
  6. Also enable Google+ API and People API in the API library
  7. Add to your .env file:
GOOGLE_CLIENT_ID=your_client_id_here GOOGLE_CLIENT_SECRET=your_client_secret_here
🐙
GitHub OAuth App
GitHub → Settings → Developer settings → OAuth Apps
  1. Go to github.com/settings/developers
  2. Click New OAuth App
  3. Set Authorization callback URL:
    http://127.0.0.1:3000/api/auth/github/callback
  4. Set Homepage URL: http://127.0.0.1:3000
  5. Click Register application
  6. Copy Client ID and click Generate a new client secret
  7. Add to your .env file:
GITHUB_CLIENT_ID=your_client_id_here GITHUB_CLIENT_SECRET=your_client_secret_here
